# assets

Drop a photo of yourself here as **`avatar.jpg`** and it replaces the ink drawing
in the hero automatically — no code change needed.

- Square-ish crop, head and shoulders, **≥ 600×600 px**
- The site applies a grayscale + contrast filter (inverted in dark mode) so the
  photo reads as pencil on the same page as the rest of the drawings
- If the file is absent, `portfolio.js` leaves the hand-drawn SVG portrait in place

Nothing else belongs in this folder — the site has no other image dependencies.
